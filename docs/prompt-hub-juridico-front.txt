- Limite rouge escuro (#2B0F12) a contornos e títulos
- Mantenha sensação geral suave e botânica
- Use creme quente como fundo predominante
- Combine com arte de linhas finas para leveza
- Papelaria artesanal e ilustrações florais como inspiração visual

### PADRÕES DE COMPONENTES

#### 1. SMART COMPONENTS (Container)
- Responsáveis por lógica, gerenciamento de estado
- Utilizam Observables do RxJS
- Passam dados para componentes apresentacionais via @Input
- Recebem eventos via @Output

#### 2. DUMB COMPONENTS (Apresentacional)
- Recebem dados via @Input
- Emitem eventos via @Output
- Sem dependências de serviços
- Altamente reutilizáveis

#### 3. COMPONENTES GENÉRICOS (Shared)
- **card.component** - Aceita @Input para título, ícone, ações
- **data-table.component** - Genérico com dados e colunas
- **bar-chart.component** - Genérico com dados e labels
- **pie-chart.component** - Genérico com dados
- **button.component** - Genérico com tipo, tamanho, cor (usa paleta)

### BEST PRACTICES ANGULAR IMPLEMENTADAS
✅ Componentes apresentacionais vs container
✅ Injeção de dependência
✅ RxJS Observables
✅ Interfaces tipadas (sem 'any')
✅ Módulos bem separados (Core, Shared, Layout, Features)
✅ Lazy loading de rotas
✅ Serviços singleton via providedIn: 'root'
✅ Componentes genéricos e reutilizáveis
✅ Async pipe no template
✅ CSS variables para tema dinâmico
✅ SCSS com variáveis centralizadas
✅ Sistema de cores coherente e escalável
